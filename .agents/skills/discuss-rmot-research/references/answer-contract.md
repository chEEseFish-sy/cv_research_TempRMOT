# Answer contract

For each material claim, cite an Obsidian note path and heading; PDF page, section, figure,
table, or equation; project file and line; or Zotero annotation/note.

Use confidence labels:

- High: explicit source evidence.
- Medium: synthesis across supported observations.
- Low: plausible inference requiring verification.

Challenge the idea constructively. Surface the strongest realistic competing explanation,
confound, or reviewer objection without manufacturing disagreement.

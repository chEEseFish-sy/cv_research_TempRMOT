# Execution contract

An executor may edit in-scope project files, run approved diagnostics/tests/inference/training,
create approved experiment artifacts, and append factual progress and findings.

An executor may not:

- change the research question, hypothesis, success/stop criteria, phase scope, or ceilings;
- edit `task_plan.md`, `approval.json`, Zotero, Obsidian, or `.obsidian`;
- start another phase;
- commit, push, or publish.

If the phase cannot proceed as written, stop with the exact failed gate and ask the director
to revise and reapprove the plan.

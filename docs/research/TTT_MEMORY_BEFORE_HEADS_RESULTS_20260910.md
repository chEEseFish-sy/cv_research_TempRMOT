# TTT 位于 STReasoner 预测头前的对照实验（2026-09-10）

## 结论

将 TTT 从“完整 STReasoner 之后”移动到“时序推理之后、当前帧 score/box/refer refinement 头之前”，成功解决了上一版本难以影响当前帧的问题，但固定六表达式验证结果变差。该变体不应继续做全量训练。

本轮证据更支持：当前同帧 key/value 重建得到的记忆残差质量不足；一旦让它直接作用于当前预测头，会干扰身份关联。正常累积与逐帧重置的离散指标完全相同，因此尚未观察到快速权重跨帧累积的独立贡献。

## 唯一算法变化

上一版本：

```text
STReasoner 时序推理 → score/box/refer 头 → TTT → lifecycle → QIM
```

本版本：

```text
STReasoner 时序推理 → TTT → score/box/refer 头 → lifecycle → QIM
```

TTT 架构、0.5 写入阈值、两层快速 MLP、训练数据、优化器、生命周期、QIM 和评测器均未改变。TTT 在新位置仍使用 Decoder 提供的预 refinement `cache_scores` 判断是否写入，因为新的当前帧 refined score 此时尚未计算。

新位置带来的直接路径是：

```text
TTT enhanced output_embedding
→ STReasoner track_cls / track_ref / track_box
→ 当前帧 score / refer / box
→ 当前帧 temporal loss 和 runtime lifecycle
```

## 训练与验证

- 同一批 100 个连续十帧片段，3 个 epoch，共 3,000 个处理帧；新 TTT 训练排除视频 0002、0006、0010。
- 仅训练 460,545 个 TTT 共享参数，TempRMOT 基线参数散列始终不变。
- 训练耗时 1,336.76 秒，约 22 分 17 秒；PyTorch 峰值分配显存 3,857.25 MiB。
- 264/300 个片段存在 TTT 任务梯度路径，259/300 个片段梯度非零。共 10,301 次写入、9,779 次读取。
- 训练结束时 `tanh(alpha)` 均值约 0.002325、绝对值均值约 0.003411、范围约 [-0.008754, 0.009804]；内部更新率约 0.010025。
- 17/17 单元测试通过。零残差时，10 帧真实序列输出与基线逐项完全一致。

训练前固定与上一实验相同的 6 条表达式，三个视频各 2 条。每个方法均处理 1,594 帧；seqmap 与六个 GT 文件完全一致。基线可直接复用，因为 TTT 关闭时的真实序列等价检查已通过。

| 原始 TempRMOT | 77.6567 | 76.9763 | 78.3660 | 78.4530 | 75.7151 | 6 | 15 |
| 头前 TTT，不在线更新 | 76.9320 | 76.8785 | 77.0074 | 77.4390 | 75.4232 | 9 | 15 |
| 头前 TTT，正常累积 | 76.9320 | 76.8785 | 77.0074 | 77.4390 | 75.4232 | 9 | 15 |

正常 TTT 相对基线：

- HOTA：-0.7247 个百分点；
- DetA：-0.0978 个百分点；
- AssA：-1.3586 个百分点；
- IDF1：-1.0140 个百分点；
- MOTA：-0.2919 个百分点；
- IDSW：+3。

CLR 计数从 TP=1,605、FN=108、FP=302 变为 TP=1,598、FN=115、FP=297。检测变化相对较小，而 AssA、IDF1 和 IDSW 明显恶化，主要风险更偏向身份关联被扰动。

## 机制判断

头前正常 TTT 发生 4,372 次写入和 5,243 次读取。累计相对残差除以读取次数约为 1.14%，显著高于旧插入位置评测的约 0.046%。它足以改变离散轨迹结果：基线 1,907 行预测，新模型 1,895 行；以表达式、帧号和 Track ID 为键，只有 1,686 行共有，说明差异已不再只是亚像素框抖动。

### `no_update` 与历史差异诊断

补充的 `no_update` 对照完全关闭在线 inner update，只保留 checkpoint 中训练后的
q/k/v、初始两层 MLP 和残差融合。三个 TTT 模式的七项汇总指标完全相同，而且都
输出相同的 1,895 个“表达式、帧号、Track ID”键。这说明本批样本中的指标退化在
没有任何在线更新时就已经出现；退化至少可归因于训练后的额外映射及其残差路径，
不需要历史累积或单帧快速更新才能发生。

为避免把“指标相同”误解为“历史没有变化”，额外记录了更新前的历史回答差异：

\[
d_{\mathrm{history}}=
\frac{\lVert f_{W_{t-1}}(q_t)-f_{W_0}(q_t)\rVert_2}
{\lVert f_{W_0}(q_t)\rVert_2+\epsilon}.
\]

正常模式的 5,243 次有效历史读取中，平均 `d_history` 为 0.017041（1.7041%），
最大值为 0.089124（8.9124%）。`reset` 和 `no_update` 按定义均为 0。也就是说，
在线累积确实改变了 fast model 的连续回答，但经过较小的 `alpha` 门控后，正常模式
的平均相对残差仅为 1.1408%，`no_update` 为 1.1336%。正常模式与 `no_update`
具有完全相同的输出键；共有框坐标分量的平均绝对差约为 `1.64e-5` 像素，最大约
`0.0020` 像素，不足以改变本批样本的离散轨迹决策。

因此更严格的结论是：当前退化的直接来源是训练后的额外特征映射与残差注入；历史
快速权重不是这批样本退化的必要条件。历史累积虽然存在，但它经过融合门后的边际
作用太弱，尚未提供可测的轨迹收益。由于三个诊断模式复用的是正常训练 checkpoint，
它们是推理时因果消融，不是分别重新训练的等预算方法。

这项实验回答了插入位置问题：旧版本弱，确实部分因为 TTT 位于预测头之后；移动到预测头之前后影响显著增强。但它同时暴露更根本的问题——当前自监督目标只要求同帧 `f_W(k_t)` 拟合 `v_t`，并不直接约束跨帧身份稳定、同 ID 一致性或异 ID 分离。增强影响力后，错误记忆同样被放大。

## 暂停条件与下一步

当前变体在预先固定的小样本上已经同时降低 HOTA、AssA 和 IDF1，不应直接扩大到全量训练或手工放大 alpha。

下一步应先设计能够区分“同一轨迹跨帧身份”与“同帧特征重建”的训练目标，并单独验证以下三项：

1. 可靠历史帧作为 stop-gradient value 时，跨帧同 ID 相似度是否改善；
2. 写入与读取门分离后，低分活轨迹能否受益且高分轨迹不被持续扰动；
3. 对额外映射采用严格 identity 初始化或零门控 warm-up，能否先保持基线再学习增益。

本轮没有执行上述新变体，也没有根据结果调参。
